    What this is

    One cross-platform console for the AEDi-Sight RuView WiFi-CSI stack. Flash and provision ESP32 nodes (1 of 8 → 8 of 8), watch the live UDP/WS sink, plot the per-subcarrier heatmap, train models, and pull repo updates — all without leaving the page.

    How a frame travels

    1. ESP32 captures CSI via promiscuous-mode callback (192 subcarriers @ ch 11).
    2. Frame serialized to ADR-018 (20 B header + I/Q int8) over UDP :5005.
    3. Sink ingests, broadcasts JSON over WebSocket.
    4. Visualizer renders subcarrier amplitude per frame.

    Mesh multiplex

    Each node owns a TDM slot 0..7 of an 8-slot cycle (≈ 4 ms TX + 30 ms processing). Per-slot one node transmits and seven receive — over a full cycle every node does both. Configure slot + node-id from the Provisioning tab.

    Provision a node

    Two-step: flash firmware once, then write NVS config. Re-running NVS write replaces the whole csi_cfg namespace (issue #391) — pass every key you want kept.
